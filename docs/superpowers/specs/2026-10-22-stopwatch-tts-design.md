# StopWatch 云端中文语音

用户已选择设备直接连接云端 TTS，并批准创建 OpenAI API 密钥。保留 Muse 录音、上传、文字对话、配对和音量控制。收到完整回复后，由独立的 PSRAM 任务使用带 CA 校验的 WebSocket 调用 OpenAI Realtime gpt-realtime-2.1-mini，仅原样朗读文字，不调用工具，不保存会话。24 kHz PCM 经现有重采样与扬声器输出。

API 密钥通过 USB 保存至独立 NVS 命名空间，不放入源码、编译配置、日志或 Git。正常状态只报告是否配置。帧大小、Base64、PCM 对齐和 UTF-8 输入均有边界检查。取消请求通过 generation 隔离旧音频；断线、超时或服务错误回退为字幕。每次仅一个合成请求，使用有界音频缓冲，避免阻塞 Muse 主连接。

主机测试覆盖密钥格式、中文与 JSON 转义、UTF-8 截断、错误事件、Base64 和大小限制。编译 StopWatch，备份当前已配对固件，刷写后验证 NVS 配对保留、设备在线及真实中文播放。最终以用户听到音频确认验收。
